# 精簡復健支援

使用者授權：分析已提供的病史，轉為必要訓練調整及運動指引；病史不納入網頁，含隱藏內容。Android、零後端、私人 Sheet 與模組隔離維持。

交付順序：
1. `rehab` 日誌型別：可編輯的動作計畫、每次獨立症狀紀錄。完整病史只存 private/，不進 app 資料。
2. 獨立驗證與分析模組：unknown 不等於 no；原始分數、實際日期、警訊分流與受限候選隔離。不推論診斷、病因、肌力不足或復健治癒。
3. Sheet 擴充：保留既有四表，首次同步 rehab 時以原子 batchUpdate 新增 rehab_log 並升級遠端 metadata；舊日誌無須搬移。升級失敗保留待同步，不覆寫既有表。
4. 精簡卡片：狀態、動作卡、記錄不適；位置圖及分數趨勢展開查看。完整病史不進 DOM、備份或發布。
5. 私人起始備份合併既有資料與一筆無病史的調整計畫；不造歷史疼痛分數、日期或當前陰性警訊。
6. 驗證：domain、日誌、Sheet 升級／讀回／故障、實際 mobile 表單／備份／離線、受限部位不列補練、公開資產與初始 app 資料無病史。

運動內容是待個別確認的起步選項，非遠端確診後處方；來源與詳細分析保存在私人審查文件，頁面只留短提示。既往誘發的重負荷單側髖鉸鏈、側屈／旋轉先暫緩；核心基礎與雙側髖伸從低負荷選項開始，當次與隔日反應未記錄前不自動升級。
