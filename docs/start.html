設定完成後，每天只做這些

  1. 打開主畫面的「練習誌」，直接點常用器材；第一次才按「其他器材」。
  2. 器材卡會帶入機台、單位、重量與組數；填本次實際次數。感受與備註可選填。
  3. 用「人體圖」看練到哪裡，用「進展」看各器材的變化。
  4. 有網路時按「同步」。需要時點「連線 Google」，確認顯示「已同步紀錄」。

第一次，照順序完成

  1. 先取得正式網站網址

    把網站程式放到 GitHub Pages。完成後，手機可直接開啟 HTTPS 網址，不必讓電腦一直開著。

    網址範例：https://你的帳號.github.io/rehab/
    這是格式範例，不是已部署的網址。電腦的 127.0.0.1 預覽網址不能直接拿到手機使用。

    交給設定者：GitHub 要做什麼
    1. 建立 GitHub repository，例如 rehab。GitHub Free 可用公開 repository 架設 Pages。
    2. 放入網站程式、測試與附帶的 .github/workflows/pages.yml。私人備份、病史與 private/ 不上傳。
    3. 進入 Settings → Pages，Source 選 GitHub Actions；執行部署，或推送 main 觸發。
    4. 取得部署結果的 HTTPS 網址。公開的是程式；Sheet 的共用設定維持「受限制」。

    GitHub Pages 方案與用途 · 部署設定

  2. 讓 Google 認得這個網站

    在 Google Cloud 設定一次，取得一串 Client ID（用戶端 ID）。它就像網站的識別證，讓 Google 能向你確認存取權限。

    交給設定者：Google 要填什麼
    1. 在 Google Cloud Console 建立專案，啟用 Google Sheets API 和 Google Drive API。
    2. 設定 Google Auth Platform：填應用程式名稱與聯絡信箱；個人帳號的 Audience 選 External。Testing 階段把自己的 Google 帳號加進 Test users。
    3. Data Access 加入 https://www.googleapis.com/auth/drive.file。這是 Google 建議的特定檔案權限。
    4. 建立 OAuth Client，類型選 Web application。
    5. Authorized JavaScript origins 填 https://你的帳號.github.io，不要加 /rehab/。自訂網域則填該 HTTPS 網域。
    6. 網站設定者把結尾為 .apps.googleusercontent.com 的 Client ID 寫入公開網站設定一次。之後新手機不必重貼。這個版本不需 API key、Client secret、Apps Script 或後端登入程式。

    Google 用戶端設定 · 存取範圍

  3. 在練習誌連上自己的 Sheet

    1. Android Chrome 開正式網址 →「資料設定」。
    2. 開啟「資料設定」，等待網站準備授權後按「連線 Google」。
    3. 選自己的 Google 帳號並授權 →「建立私人試算表」。所需欄位會自動建立。
    4. 如已有本機紀錄：先從舊版「匯出備份」，到正式網站「匯入 JSON 備份」，再同步。舊預覽資料不會自動搬到新網址。
    5. 確認「已同步紀錄」後，可從 Chrome 選單選「加到主畫面」／「安裝」。名稱依 Chrome 版本而異。

    以後不必重貼 ID 或重建 Sheet。連線成功會顯示「已連線」；有效期間重新整理可續用。授權到期或分頁工作階段結束後，才需要重新連線。

InBody、身體不適，要另外接系統嗎？

不用。InBody 按「記錄 InBody」手動輸入，隔幾週才測也可以；日期會依實際量測間隔呈現。沒有的數值留白。

訓練中的感受填在該筆訓練內。隔天或持續不適，才使用下方收起的「不適追蹤」。目前沒有直接連 InBody 機器、照片辨識或 AI 自動解析。

可以直接在 Google Sheet 改數字嗎？

目前請在練習誌新增或修改。Sheet 保存的是含歷史版本的同步日誌，手動改欄位、刪列或加公式可能破壞同步格式。

「可從 Sheet 重新載入」是還原這套系統保存的資料，不是匯入任意格式的健身試算表。

換手機，怎麼把紀錄找回來？

先讓舊手機顯示「已同步紀錄」。新手機開同一正式網址、連線相同 Google 帳號，按「尋找既有試算表」→ 選原本那份 →「載入選取的試算表」。不要另建空表。

也可以在舊手機匯出 JSON 備份，在新手機匯入。未同步、又沒有備份的紀錄，不能從雲端找回。

同步不成功，先看哪裡？
  • 尚未連線／已到期：按同步進設定，再按「連線 Google」。
  • origin_mismatch：核對 Google 設定中的網站來源，不能包含路徑。
  • access_denied：核對 Test users、登入帳號及機構帳號限制。
  • 找不到原本的表：確認同一 Google 帳號與同一 Cloud 專案。它不會列出所有 Drive 檔案。
  • 格式損壞：先匯出手機備份，保留 Sheet 原檔，請設定者檢查；不要清空資料重試。

Google 的瀏覽器授權需要使用者點擊；到期後重新取得權杖是此架構的操作限制。Google 授權方式

第一次設定用電腦較方便；設定完成後，日常記錄、查看圖表與重新連線可在 Android 上操作。

本指南說明設定方式，不代表你的帳號已完成部署或授權。正式上線後，仍要實測一次同步、離線記錄與換機載入。
